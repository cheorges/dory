## Side findings

- After renaming the repo folder, a running session keeps writing its transcript to the old project folder under `~/.claude/projects/`. The catch-up searches all project folders anyway (`*/*.jsonl`), so this has no effect.
- A `claude -p` call without `--no-session-persistence` creates its own project folder for the working directory. The writer sets the flag, so nothing is created there.
